## Sosyal Avcısı (6. sınıf Sosyal Bilgiler)

`sosyal/` klasöründe: Maarif Modeli 6. sınıf Sosyal Bilgiler'in 6 öğrenme alanı, 19 görselli ders, 215 soru (çoktan seçmeli, doğru/yanlış, eşleştirme, sıralama, boşluk doldurma, haritada bulma, koordinat avı), ünite sınavları, hata kutusu, günün meydan okuması, yıldırım turu, rozetler, sınıf ligi ve öğretmen paneli.
